# LBGM · 英雄音乐台

一个运行在本机的英雄联盟音乐音效板：自动识别你正在选用/锁定的英雄，为每个英雄绑定最多三段本地音乐，游戏里按 `Ctrl+1/2/3`（可自定义）即可向 QQ 语音播放，自己也能在耳机里同步听到，且不会回听自己的麦克风。

> 本工具只读取英雄联盟客户端的本机接口（LCU）获取英雄选择状态：不修改游戏文件、不注入进程、不读取内存、不执行任何自动选人等客户端操作。LCU 并非 Riot 对第三方承诺的稳定公开 API，版本更新后可能需要适配；使用第三方工具的账号风险无法承诺为零，请自行评估。

## 应用场景

- **和朋友开黑整活**：选人阶段锁定英雄后，按一个键就能在语音里放出为这个英雄准备的名场面音乐/BGM/空耳，朋友在语音里直接听见。
- **高光时刻配乐**：五杀、极限反杀时来一段应援曲；三条快捷键对应三段音乐，可以按"登场曲 / 高光曲 / 败北曲"分类准备。
- **英雄指代不明时的兜底**：自动检测偶尔不认识新英雄时，可以手动指定英雄，或干脆只当普通音效板用——手动选择的英雄仅当次运行有效。

## 功能一览

- **英雄自动检测**：读取客户端 LCU 接口，识别选人界面的预选/锁定英雄与游戏内的当前英雄；支持 WeGame/Tencent 客户端（自动读取客户端进程凭据）与国际服（lockfile）。
- **每英雄三段音乐映射**：本地 mp3/wav/ogg/m4a/flac，不复制不移动你的音频文件。
- **游戏内全局快捷键**：默认 `Ctrl+1/2/3` 播放、`Ctrl+A` 暂停/继续，四个键位均可在界面内捕获式改键（Ctrl/Shift + 字母/数字/F1~F24）；游戏全屏时依然有效。
- **暂停续播**：同键再按即暂停，再按从原进度继续。
- **双路输出**：音乐一路经 Voicemeeter B1 进入 QQ 作为麦克风输入，一路直连物理耳机本地监听；你听得到音乐，听不到自己的麦克风回声。
- **响度处理**：可选"QQ 弱网模式"（语音频段化，抗弱网）或"响度稳定器"（保真前提下压平动态，防止安静段落被 QQ 吞掉），两者互斥。
- **一次性音量校准**：对麦克风说 5 秒话，自动固定麦克风增益与音乐音量配比。
- **新英雄自动适配**：检测到未知英雄时自动刷新列表；英雄"本名"（如 亚索→疾风剑豪）从官方数据自动抓取，常见昵称（狗头、瞎子等）内置搜索映射表。
- **贴心的窗口行为**：无边框深色界面、关闭时确认最小化到托盘还是退出（可记住选择）、音乐映射不随重启残留。

## 安装与使用教程

### 0. 系统要求

- Windows 10/11 x64
- 英雄联盟（WeGame/Tencent 或 Riot 国际服）安装在本机
- [Voicemeeter](https://vb-audio.com/Voicemeeter/index.htm)（免费软件，向导可自动下载安装）
- QQ（NT 版本，PC 客户端）

### 1. 安装

1. 从 [Releases](../../releases) 下载 `LBGM-Setup-x.x.x.exe` 并安装。
2. 首次启动会弹出**初次配置向导**：
   - **① Voicemeeter**：未安装时点击"从官网下载并安装"（约 15MB，来源为 VB-Audio 官方站点），按官方安装向导一路下一步；
   - **② 选择耳机和麦克风**：在下拉框中选择你日常使用的耳机（输出）与麦克风（输入）；
   - **③ 一键配置**：自动设置系统默认设备、写入 Voicemeeter 路由（麦克风→B1、增益 +12dB）并创建**管理员桌面快捷方式**。
3. 之后请**始终从桌面快捷方式"英雄音乐台"启动**（带管理员权限，否则游戏内按键与英雄检测可能失效）。

### 2. QQ 侧设置（一次性）

1. QQ → 设置 → 音视频通话 → 麦克风选择 **Voicemeeter Out B1 (VB-Audio Voicemeeter VAIO)**；
2. 关闭"自动调整麦克风音量"等自动项；若通话设置里有"智能降噪/AI 降噪"，建议关闭（防止音乐被当作噪声削减）。

### 3. 日常使用

1. 从桌面快捷方式启动，进入英雄联盟；
2. 选人界面锁定英雄后，界面会显示"已锁定：×××"；
3. 给这个英雄导入 1~3 段音乐并点击"保存三条映射"；
4. 游戏内按 `Ctrl+1/2/3` 播放，再按同键暂停、再按继续；`Ctrl+A` 暂停当前音乐；
5. 换英雄时映射自动跟随检测结果；自动检测不认识时可手动指定英雄（仅本次运行有效）。

### 4. 常见问题

| 现象 | 处理 |
|---|---|
| 检测不到英雄 | 确认从管理员快捷方式启动；客户端是否运行；`%APPDATA%\champion-soundboard\lcu-discovery-status.json` 记录了发现详情 |
| 游戏内按键无效 | 必须从管理员快捷方式启动；确认 `Ctrl+1` 未被其他程序占用 |
| 对方听不到音乐 | QQ 麦克风是否选择了 Voicemeeter Out B1；Voicemeeter 是否运行且 B1 未静音 |
| 音乐低音/高频丢失 | 关闭"QQ 弱网模式"（它会刻意压成语音频段）；QQ 的 AI 降噪也可能吃掉合成音色 |
| 双耳不同步/回声 | 确认"自己监听"选择物理耳机而非 Voicemeeter 设备 |

更深入的排障手册正在整理中；当前版本可直接在 Issue 中反馈问题。

## 工作原理（简述）

```text
英雄联盟客户端 ──只读 LCU/Live Client──► 英雄识别
本地音频文件 ──► 播放器+响度处理 ──► Voicemeeter 虚拟输入 ──► B1 ──► QQ（麦克风输入）
                     └──► 物理耳机（本地监听，不经过 Voicemeeter A 通道）
耳机麦克风 ──► Voicemeeter Hardware Input 1 ──► B1 ──► QQ
```

## 从源码构建

```powershell
git clone <本仓库>
cd LBGM
npm install
npm run build   # 编译 C# 辅助程序 + JS 语法校验
npm start       # 开发运行
npm run dist    # 生成 NSIS 安装包（输出到 release/）
```

开发要求：Node.js 22+、.NET Framework 64 位编译器（Windows 自带）。架构、排障与实现细节的深度说明正在整理为独立文档。
