# LBGM · 英雄音乐台

面向英雄联盟的本地 BGM 工具。自动识别当前英雄，通过快捷键播放本地音乐；音乐可同时发送到 QQ 语音与物理耳机，本地监听不经过麦克风回听通道。

当前版本：**v1.2.0** · Windows 10/11 x64 · [下载安装包](https://github.com/zouludaixiu/LBGM/releases/latest) · [详细使用说明](docs/V1.2.md)

v1.2 使用 **LBGM 内部混音 + VB-CABLE**，不再依赖 Voicemeeter。Windows 默认音频设备保持不变；从旧版升级需重新选择真实麦克风、耳机和 CABLE 输出，原音乐库及快捷键保留。

## 功能

### 英雄识别与音乐匹配

- 自动识别预选、锁定及游戏中的当前英雄，支持 WeGame/Tencent 客户端与 Riot 客户端的连接方式；也可手动选择 lockfile。
- 支持手动指定英雄，以及称号、名称和常见昵称搜索。手动指定仅本次运行有效，可随时恢复自动检测。
- 每个英雄最多配置 3 段专属音乐；公共音乐池另提供 3 个通用槽位，无需提前配置所有英雄。
- 默认按槽位优先使用英雄专属音乐，空槽回退公共池；未检测到英雄时也能使用公共池。可切换为“仅公共音乐池”。
- 当前英雄快捷配置、最近使用的 8 名英雄列表，便于逐步完善音乐库。点击最近英雄只打开编辑，不改变播放英雄。
- 自动加载英雄列表与头像；头像优先读取客户端资源，必要时使用官方 Data Dragon 并缓存。资源不可用时显示占位图，不阻塞音乐播放。

### 音乐管理与片段编辑

- 导入本地 MP3、WAV、OGG、M4A、FLAC 文件，支持替换、试听和清空槽位。
- 起点、终点均支持滑块拖动或精确输入；时间可使用秒数或 `分:秒`，结束留空表示文件结尾。
- 尚未保存也能试听所选完整片段；支持试听暂停、续播和进度拖动，到终点自动停止。
- 片段仅保存播放范围，不复制、移动或改写原始音频。文件移动或删除后需要重新导入。
- 修改后点击“保存三条映射”生效；切换编辑对象时，未保存提示可选择继续编辑或放弃修改。

### 播放与快捷键

| 操作 | 新安装默认键位 | 行为 |
| --- | --- | --- |
| 播放槽位 1 / 2 / 3 | `Ctrl+1` / `Ctrl+2` / `Ctrl+3` | 播放对应音乐；相同键再次按下暂停，再按续播 |
| 暂停 / 继续 | `Ctrl+A` | 控制当前 BGM，保留暂停位置 |
| 从头重播 | `Ctrl+4` | 将当前播放或暂停的 BGM 从片段起点重播 |

- 三个播放键和暂停键可在界面中捕获式修改，支持 Ctrl、Shift 或二者叠加，再加字母、数字或 F1～F24；不支持 Alt。
- `Ctrl+4` 为固定重播键。没有当前 BGM 时仅显示提示，不自动选择音乐。
- 切换槽位从新片段起点播放；片段结束后再次播放从该片段起点开始。
- 首页音乐卡片与底部状态栏也可播放、暂停，并显示当前来源和进度。全局快捷键用于游戏期间操作。

### 音频输出与音量

- 语音发送：LBGM 采集明确选择的真实麦克风，与 BGM 实时混合后输出至 CABLE Input；QQ 麦克风选择 CABLE Output。
- 本地监听：仅 BGM 直接输出到物理耳机，麦克风不进入监听；游戏和系统声音不参与混音。
- 语音发送与本地监听音量独立可调；试听使用监听音量，可将任一路音量设为 0。
- 提供耳机、虚拟输出测试，以及设备刷新、重新配置入口；人声、BGM 与总混合电平分别显示，设备不可用或播放失败时显示状态提示。
- 麦克风增益可独立调节；默认全频段立体声，混合总线带峰值保护。可选一次性音量校准：正常说话约 5 秒，计算并保存麦克风增益与语音音乐音量，不录音、不保存语音，也不在每次播放时重新校准。
- **QQ 弱网模式**：仅处理语音发送的音乐，使用单声道、语音友好频段和动态压缩，本地监听保持原音。
- **响度稳定器**：保留立体声和频段，压缩动态、抬高安静段。与弱网模式互斥。

这两种处理只改变本地送出的音频，不能修复网络丢包，也不能保证绕过 QQ 的降噪或静音判定。

### 界面与配置

- 浅色卡片界面，展示当前英雄、头像、音乐来源与播放状态；音乐库和音频设置可折叠。
- 首次配置向导检测 VB-CABLE、读取真实耳机及麦克风并连接混音；支持超时提示、失败重试及稍后配置。
- 关闭窗口可选择托盘运行或退出；退出前提醒 QQ 切回真实麦克风。托盘运行时英雄检测、快捷键和已连接的人声混音继续工作。
- 已保存的映射、片段、音量与键位重启保留；不添加开机自启动。

## 快速开始

1. 从 [Releases](https://github.com/zouludaixiu/LBGM/releases/latest) 下载并安装。安装包未签名，Windows 可能提示 SmartScreen，请核对来源后运行。
2. 安装普通版 [VB-CABLE](https://vb-audio.com/Cable/)，按驱动要求重启，再在 LBGM 向导中选择真实耳机、麦克风与 CABLE Input。Windows 默认设备保持真实耳机及麦克风。
3. QQ 麦克风手动选择 **CABLE Output**，扬声器选择真实耳机。在 LBGM 连接麦克风或按播放键建立混音；每次启动不会自动采集。退出 LBGM 后如需继续通话，QQ 麦克风切回真实设备。
4. 打开“管理音乐库 → 公共音乐池”，导入 1～3 段音频，可选择片段，然后点击“保存三条映射”。无需启动游戏即可测试播放。
5. 日常从“英雄音乐台”管理员快捷方式启动。检测到英雄后自动匹配音乐，也可随时添加专属配置。实际键位以设置面板显示为准。

QQ 版本不同，降噪、自动增益等选项不一定可见；若存在且音乐被明显削弱，可尝试关闭后比较效果。

## 升级与兼容

- v1.2 保留已有英雄映射、公共池、片段、音量和有效自定义键位，包括旧版 `Shift+1/2/3`。
- 从 Voicemeeter 版升级需重新配置 VB-CABLE。内部麦克风增益默认 0 dB，不直接套用旧方案的增益；旧软件和驱动不会被安装包自动卸载。
- 每次启动不自动持续采集麦克风；连接或首次播放后开始混音。退出或断开后，语音软件需切回真实麦克风。
- 开发测试版使用独立配置目录，安装正式版不会自动合并测试库，详见 [升级说明](docs/V1.2.md#从-v11-升级)。
- 首次升级自动备份 `%APPDATA%\champion-soundboard\settings.before-v1.1.json`，后续启动不覆盖该备份。
- 唯一键位例外：旧配置若占用 `Ctrl+4`，该冲突项会迁移至首个未占用的 `Ctrl+F1～F24`，其余键位不变。
- 升级前请保存修改并从托盘完整退出。关闭窗口但仍留在托盘，不会加载新版程序。

## 常见问题

| 问题 | 检查项 |
| --- | --- |
| 检测不到英雄 | 客户端是否运行；是否从管理员快捷方式启动；必要时手动选择 lockfile 或指定英雄 |
| 游戏内快捷键无效 | 是否以管理员权限启动；键位是否被其他程序占用；修改后是否确认保存 |
| QQ 对方听不到音乐 | QQ 输入是否选择 CABLE Output；混音是否已连接；应用混合输出是否选择 CABLE Input；发送音量是否为 0 |
| 试听或监听无声 | “自己监听”是否选择物理耳机；监听音量是否为 0；使用“测试耳机”检查 |
| 听到自己的麦克风回声 | 检查 Windows“侦听此设备”及对端扬声器回声；应用音乐监听本身不需要麦克风回听 |
| 音乐失真、被截断或通话卡顿 | 比较关闭弱网模式、QQ 降噪后的效果；检查网络与麦克风链路。本地输出成功不代表远端接收完整 |
| B 站、网易云等无声 | 检查系统和对应应用的输出是否指向物理耳机；可重新运行音频配置向导 |

反馈问题请使用 [Issues](https://github.com/zouludaixiu/LBGM/issues)，附复现步骤和必要日志，避免公开设备标识、个人路径、客户端凭据或完整配置。

## 实现与限制

英雄识别读取本机 LCU / Live Client 接口；不注入进程、不读取游戏内存、不修改游戏文件，也不自动选人。头像等资源可能访问官方网络服务，音乐及个人映射保存在本机。

LCU 不是 Riot 对第三方承诺稳定的公开接口，客户端更新后可能需要适配。本项目不承诺第三方工具的账号风险为零。片段停止受播放器调度影响，不属于采样级音频剪辑。

应用只能检测本地设备与播放状态，无法读取 QQ 内部设置或确认远端听感。发布验证范围见 [v1.2 验证记录](docs/QA-v1.2.md)。

## 从源码构建

需要 Node.js 22+ 与 Windows 自带的 .NET Framework 64 位编译器。构建前请退出本应用。

```powershell
git clone https://github.com/zouludaixiu/LBGM.git
cd LBGM
npm install
npm run build
npm test
npm run test:renderer
npm run test:internal
npm start
# 打包前先从托盘退出应用
npm run dist
```

安装包输出至 `release/`。界面测试使用隔离配置和模拟设备，不修改实际音乐库或系统默认设备。
