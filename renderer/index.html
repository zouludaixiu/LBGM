音频配置向导

  1. ① 安装普通版 VB-CABLE

    检测 CABLE Input / Output…

    下载普通版 Windows 驱动，无需 A+B / C+D。解压后管理员安装并重启，再点击“刷新设备”。LBGM 不捆绑驱动、不更改 Windows 默认设备。

  2. ② 选择你的耳机和麦克风
    正在读取音频设备…

    选择平时使用的真实耳机和麦克风。虚拟音频设备不会出现在这里。
