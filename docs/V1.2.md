# LBGM v1.2 · 内部混音版

v1.2 将音频路由整合进 LBGM，只需额外安装普通版 VB-CABLE。无需安装或运行 Voicemeeter。英雄识别、公共池、三槽位、片段管理和原有快捷键逻辑保持不变。

## 首次使用

1. 下载并安装 [普通版 VB-CABLE](https://vb-audio.com/Cable/)，按官方要求重启电脑。驱动单独安装，LBGM 不捆绑驱动，也不会自动卸载其他音频软件。
2. 安装 LBGM，从桌面“英雄音乐台”启动。在向导中选择真实耳机、真实麦克风和 **CABLE Input**，点击“完成配置并进入”。
3. QQ 或其他语音软件的麦克风手动选择 **CABLE Output**，扬声器选择真实耳机。Windows 默认输入、输出继续使用真实设备，不要改为 CABLE，也不要开启“侦听此设备”。
4. 在公共音乐池导入并保存 1～3 首音乐即可开始使用。默认 `Ctrl+1/2/3` 播放对应槽位，`Ctrl+A` 暂停/继续，`Ctrl+4` 从当前片段起点重播；已有自定义键位继续保留。

音乐库、英雄昵称搜索、片段拖动和保存流程沿用 [v1.1 音乐管理说明](V1.1.md)；其中旧音频路由内容仅适用于历史版本。

## 麦克风与监听

- 连接后，LBGM 持续向 CABLE 发送真实麦克风与 BGM 的混合声音。暂停、切换 BGM 或片段播放结束不会中断人声。
- 耳机只播放 BGM，不接麦克风流。系统、游戏和浏览器的声音不参与混音；请保持这些应用输出到真实耳机。
- 音乐发送、耳机监听与麦克风增益独立可调并保存。内部麦克风增益默认 0 dB，不直接套用旧 Voicemeeter 的增益。
- 每次启动不会自动采集。点击“连接麦克风”或按音乐播放键建立连接；最小化到托盘后仍继续传输。
- “麦克风静音”只关闭人声；“断开全部音频”或退出应用则停止全部混音。此后需要在 QQ 中将麦克风切回真实设备，才能继续通话。
- 需要佩戴耳机。用手机给自己打电话、对端扬声器外放或 Windows 侦听都可能产生回声。

## 设备检查与异常

设置中可授权/刷新设备、重新配置、测试耳机和测试虚拟输出。电平条分别显示人声、音乐与总混合电平。

虚拟输出测试向 CABLE 发送短测试音，不通过耳机回听；可让 QQ 对方确认接收。界面只能确认本地连接，不能确认远端听感。

设备被拔出、麦克风权限被拒绝、输出绑定失败或音频引擎暂停时，混音停止并显示提示，不自动回退到系统默认设备。恢复设备或权限后点击重新连接。设备编号变化时，仅自动恢复唯一同名设备；多个同名设备需要手动选择。

默认保持全频段立体声，混合总线有峰值保护。弱网模式和响度稳定器是可选音乐处理，不处理人声，二者互斥；不能解决 QQ 的网络丢包，也不能修复采集前已经发生的失真。

## 从 v1.1 升级

- 升级前保存修改并从托盘完整退出。原英雄映射、公共池、片段、音量和有效自定义快捷键保留，音乐原文件不移动、不复制。
- 原配置在迁移前自动备份；首次配置内部混音前另保存 `settings.before-internal-audio.json`，不覆盖已有备份。
- 旧 Voicemeeter 配置不会重新生效。首次升级需要安装 VB-CABLE 并重新选择耳机、麦克风和混合输出；旧的 +12 dB 不自动施加到内部麦克风。
- 安装 LBGM 不会卸载 Voicemeeter，也不会移除其驱动。旧版可留在历史 Release 中，当前应用没有兼容切换入口。
- 正式版配置位于 `%APPDATA%\champion-soundboard\settings.json`。此前 `--audio-preview` 测试版使用独立目录 `%APPDATA%\lbgm-internal-preview`；测试版后来新增的映射不会自动写回正式配置。请先备份，再在完整退出两版后迁移所需设置；更换目录后可能需要重新选择设备。
- 未添加开机自启动，不修改 QQ 设置或 Windows 默认音频设备。

## 兼容与验证边界

Windows 10/11 x64。英雄检测仍只读取本机 LCU / Live Client 接口，不注入、不读取游戏内存或修改游戏文件。第三方接口与客户端更新可能产生兼容变化，不承诺账号风险为零。

发布验证见 [v1.2 验证记录](QA-v1.2.md)。安装包未签名，下载时应核对来源与 SHA256；本项目不打包 VB-CABLE 驱动，也不代替 QQ 的设置或网络质量保障。
