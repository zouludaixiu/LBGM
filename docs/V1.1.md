# LBGM V1.1

## 开始使用

首页展示当前英雄、自动/手动模式、三段可播放音乐及其来源。点击音乐卡片播放或暂停；没有配置的槽位会打开公共池配置。

“手动指定英雄”是可展开按钮，选择后显示“恢复自动”。“管理音乐库”默认折叠，标题下展示公共池数量和已配置英雄数量；没有任何音乐的新用户首次进入时自动展开。点击“配置当前英雄”或“最近使用”中的英雄，会展开管理区并定位其专属配置。最近英雄入口用于编辑，不改变当前播放英雄。

1. 打开公共音乐池，导入 1～3 首本地音频并保存。
2. 使用已经设置的三组快捷键播放；没有选人时也能播放公共池。
3. 在对局中逐渐给常玩的英雄配置专属音乐。专属槽位为空时会使用公共池同一槽位。
4. “仅公共音乐池”会暂时忽略所有英雄专属配置，随时可切回自动。

最近使用英雄在锁定、进入游戏或手动指定时记录，最多 8 名。点击最近英雄用于编辑，**不会改变当前快捷键的英雄来源**。手动指定仍只在本次运行有效。

## 编辑片段

点击槽位的“片段”。时间支持 `75`、`1:15`、`1:15.5` 等格式；结束留空表示播放到文件结尾。定位滑块可辅助设置起点或终点。“试听片段”仅发往耳机。

点击“应用片段”后仍需“保存三条映射”，与已有保存方式一致。只增加 `startTime` / `endTime` 元数据，原文件不复制、不改写。旧映射没有范围时播放整首。

开始与结束都有独立拖动滑块，选中时长实时显示。“试听完整片段”使用当前编辑范围，即使还没保存也能听；支持暂停继续和拖动试听进度，到终点自动停止。保存映射时也会保存当前尚未应用的有效片段范围。

未保存时切换编辑对象会显示应用内浅色确认窗口：“继续编辑”保留草稿，“放弃修改”才切换。清空音乐配置也使用同一风格的提示。

相同快捷键再次按下会暂停，再按从暂停位置继续；到片段结束后再按会从片段起点重播。切换其他槽位从新片段的起点播放。边界停止使用媒体事件和 50 ms 检查，精度受 Chromium 调度影响，适合 BGM 片段，不作为采样级音频剪辑工具。

`Ctrl+4` 为固定重播键：将当前正在播放或暂停的 BGM 从所选片段起点重新播放，耳机监听和语音输出同步重启。没有播放过音乐时显示提示，不会自动选择其他音乐。该键位不允许分配给播放/暂停，避免冲突。

若旧配置已将 Ctrl+4 分配给其他操作，升级时仅将冲突项改为首个未占用的 Ctrl+F1～F24；其余键不变，原键位仍在升级备份中。

## 输出和音量

配置向导会去除浏览器设备名的 `Default -` / `Communications -` 前缀，并合并重复的默认/通信设备项。只在真实路由配置成功后保存完成状态。麦克风授权、设备读取和后台配置都有等待上限；失败后显示错误并恢复重试按钮。可以稍后配置，也可在设置中点击“重新配置音频”再次打开。

“发送到语音”控制虚拟设备输出；“自己监听”控制物理耳机与试听。首次升级独立监听音量继承原音乐音量；不会重新校准麦克风。

“测试耳机”输出测试音到监听设备。“测试虚拟输出”输出到所选虚拟设备，需要在 QQ 通话中确认对方是否听到。应用只能确认本地播放和设备连接，无法读取 QQ 内部输入设备或远端接收状态。

设备变化时暂停正式播放，并提示重新检查。设备绑定失败时不会偷偷转到默认设备播放音乐。测试和试听会先暂停正式音乐；恢复正式音乐时停止试听/测试。

## 数据兼容

- 保留 `mappings` 的原键与三槽位结构。
- 新增 `publicTracks`、`monitorVolume`、`recentChampions`、`playbackMode`。
- 原有 Shift/Ctrl 自定义键位均保留，不再强制迁移旧 Shift 默认键。
- 第一次升级保存 `settings.before-v1.1.json`；后续启动不覆盖备份。
- 保存队列串行写临时文件后替换，避免最近英雄记录与手动配置同时保存造成冲突。
- 无开机自启动；托盘关闭逻辑沿用已有设置。

## 英雄头像

优先访问本机 LCU 图片资源，失败后从官方 Data Dragon 按英雄 ID/alias 取得方形头像；保存在 `%APPDATA%\champion-soundboard\champion-avatars`。离线且无缓存时显示占位图，不影响识别或音乐播放。首次图片加载不会阻塞 LCU 检测轮询。

## 验证

自动检查：`npm test` 包含配置备份、旧映射/快捷键兼容、并发保存、公共池回退、最近英雄、音频读取权限和片段边界。`npm run test:renderer` 加载真实 HTML/CSS/JS，用静音 WAV 和独立临时配置测试片段播放、暂停续播、输出失败、双路音量及界面布局。

界面测试使用模拟设备绑定和客户端事件，因此仍需真实联调：

1. 从日常管理员快捷方式启动，检查已有映射与音量。
2. 导入公共音频，设置起止范围并保存，按现有快捷键播放。
3. 进入英雄选择阶段，验证预选/锁定和头像，检查专属优先与空槽补位。
4. 游戏前台测试三组快捷键和 Ctrl+A，确认暂停位置保持。
5. QQ 通话中由对方确认音频；本地耳机确认监听，分别调整两路音量。
6. 重启应用检查片段和映射保留；确认 B 站/网易云及麦克风路由正常。
