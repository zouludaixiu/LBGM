# 配套音乐资源包

本资源包由项目作者个人整理，作为 LBGM 的可选配套资源提供。本次整理与分享未进行商业用途，供非商业个人体验使用；软件本身不依赖此资源包。

## 下载与使用

从 [v1.1.0 Release](https://github.com/zouludaixiu/LBGM/releases/tag/v1.1.0) 下载 `LBGM-Music-Pack-1.1.0.zip`，解压至准备长期保留的目录。

1. 在应用中展开“管理音乐库”。
2. 选择“公共音乐池”，或在“英雄专属”中搜索对应英雄。
3. 点击槽位“导入”，选择解压后的 MP3；需要时设置播放片段。
4. 点击“保存三条映射”。每个英雄或公共池最多设置 3 段音乐。

文件名是作者的整理标记，方便选择英雄对应素材，不代表作品正式名称、作者信息或来源说明。带数字后缀的文件是独立素材，并非固定槽位；`akl.mp3`、`亚非1.mp3` 等名称按原样保留，导入时自行确认。

本包不会自动添加或替换现有音乐映射。应用引用解压后的文件路径，不复制音乐；保存映射后请勿移动或删除对应文件。
